## 📝 Descrição do projeto
Este projeto se trata de um site realizado em um trabalho acadêmico e interdisciplinar no ano de 2024.<br>
Consiste na listagem de itens, chamados de "skins", que são, basicamente, desenhos para as armas do jogo "Counter-Strike 2".<br>
Possui sistema de filtragem, como o filtro por nome e categoria, e ordenação por nome ou raridade.<br>
Os dados exibidos são obtidos através de uma API criada pelo usuário ByMykel. Ela pode ser encontrada <a href="https://github.com/ByMykel/CSGO-API">aqui</a>.<br>
Além disso, o site é totalmente responsivo, implementado apenas com o CSS de forma modular.
